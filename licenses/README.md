# Third-party notices

- `FluidR3Mono_License.md`: notice for `FluidR3Mono_GM.sf3` (MIT), the SoundFont that
  `scripts/bootstrap.py` downloads from MuseScore tag `2.1`. Kept byte-identical to that
  tag (SHA-256 `09926f9451f751408abd65162c99343f840234d2a708584808fd46427633063f`).
- `codecs/`: license texts for external codec packages built via Bazel (`vendor/engrave/bazel/deps.bzl`):
  - `fdk-aac/NOTICE`: Fraunhofer FDK AAC license notice (v2.0.3)
  - `flac/`: Free Lossless Audio Codec licenses (v1.4.3: COPYING.FDL, COPYING.GPL, COPYING.LGPL, COPYING.Xiph)
  - `lame/`: LAME MP3 encoder licenses (v3.100: COPYING, LICENSE)
  - `opus/`: Opus codec license (v1.5.2: COPYING - BSD-3-Clause)
  - `opusenc/`: libopusenc license (v0.2.1: COPYING - BSD-3-Clause)
